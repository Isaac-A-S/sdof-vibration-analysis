# Generated Figures


Running ../matlab/run_analysis.m exports the following 300 dpi figures to this directory:


- **free_response_comparison.png** — normalized displacement for all damping cases, including the ±2% band.


- **energy_decay.png** — normalized mechanical energy on a logarithmic scale.


- **settling_time_sweep.png** — 2% settling time versus damping ratio, with the 2% reverse-peak design and critical damping identified.


Commit the generated PNG files before publishing the repository so the README can show the project results without requiring visitors to run MATLAB.
